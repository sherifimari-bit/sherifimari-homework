# Использование LLM при выполнении домашних заданий

## DeepSeek Chat

### Как я использовал
Я использовал веб-версию DeepSeek Chat (chat.deepseek.com) для получения помощи в выполнении домашнего задания по созданию Snakemake workflow и работе с Git.

### Пример запроса к DeepSeek
```
Домашнее задание:
- Установить Git или работать в том же Docker контейнере debian. VS Code позволяет подключиться к докер контейнеру, на счёт продуктов JetBrains точно не могу сказать, но скорее всего тоже можно
- Зарегистрироваться на GitHub/GitLab
- Создать git репозиторий git init (или следовать инструкции в GitHub/GitLab после создания репы) и создать новую ветку
- Создать Snakemake/Nextflow workflow с любой командой на ваш выбор. Это может быть что угодно, bash команда, R/Python скрипт, мб что-то ещё, главное чтобы корректно отработало
- Закоммитить и запушить ваши изменения в удалённую репу. Удобнее всего это делать не через терминал, а через редакторы кода, но на ваш выбор
- В вашем репозитории создать Pull Request на внесение изменений в вашу основную ветку

Требования к ДЗ - наличие полноценного Readme.md, в котором описано как запускать ваш проект и код. Я буду следовать чётко по вашей инструкции, поэтому если я не смогу по этой инструкции получить корректный вывод, то ДЗ считается не сданным. будьте внимательны. Можете там описать какой вывод я получил, чтобы уж наверняка
как это сделать? Я установил гит и создал аккаунт на гитхаб
```

### Пример ответа DeepSeek (сокращённо)
```
Отлично! Вы выполнили первые шаги. Теперь я помогу вам создать полноценное домашнее задание. Вот пошаговый план:

## 📋 Пошаговый план выполнения ДЗ

### 1. **Создайте репозиторий на GitHub**
   - Зайдите на github.com
   - Нажмите "+" в правом верхнем углу → "New repository"
   - Название: `snakemake-homework` (или любое другое)
   - Описание: "Homework for bioinformatics course"
   ...

[Далее шли подробные инструкции по созданию Snakefile, Python скрипта, README.md и .gitignore]
```

### Как я работал с DeepSeek
1. **Постановка задачи**: Я подробно описал задание, скопировав его из ТЗ
2. **Уточнение**: Указал, что уже сделал (установил Git, создал аккаунт на GitHub)
3. **Итерации**: 
   - Сначала получил общий план
   - Потом просил упростить (например, сделать скрипт просто `print("Hello world")`)
   - Просил переписать README.md в разных стилях
   - Задавал уточняющие вопросы (например, как назвать файл Snakefile)
4. **Решение проблем**: Когда возникали ошибки (как с настройкой Git), я показывал сообщение об ошибке и получал решение

### Что я узнал с помощью DeepSeek
- Правильное именование файлов Snakemake (Snakefile без расширения)
- Структуру проекта для Snakemake workflow
- Как писать понятные README.md файлы
- Как исправлять ошибки с настройкой Git
- Как создавать Pull Request на GitHub

### Преимущества использования DeepSeek для учёбы
1. **Мгновенная обратная связь** - не нужно ждать ответа преподавателя
2. **Пошаговые инструкции** - можно выполнять задание постепенно
3. **Разные варианты решения** - можно попросить несколько подходов к одной задаче
4. **Объяснение ошибок** - когда что-то не работает, можно получить объяснение почему
